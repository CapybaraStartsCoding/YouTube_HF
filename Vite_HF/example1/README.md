# How to Launch the App

### 1. Install Dependencies
* Open your **terminal**.
* Change directory to example1 folder
* Run the installation command: `npm install`
* Press **Enter** to install all packages.

### 2. Insert your own TOKEN in constants.js file

### 3. Launch the App
* In the same terminal, run: `npm run dev`
* Press **Enter** to start the local server.
